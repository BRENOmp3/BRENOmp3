### 🛠️ O que tenho construído no trabalho

- **Serviço de monitoramento (Worker Service / Windows Service, .NET)**
  Monitora serviços do Windows definidos num arquivo JSON, detecta quando um serviço parou ou travou (pelo crescimento do log), tenta a recuperação automática com novas tentativas e envia alertas por email indicando de qual servidor veio o problema. Está sendo implantado em vários servidores da empresa.

- **Portal de consultas SQL (ASP.NET Core + Angular)**
  API e front-end que permitem a administradores consultar e editar dados no SQL Server sem acesso direto ao banco. A API valida os comandos com ScriptDom pra restringir o acesso às tabelas permitidas, usa transações e pede confirmação antes de alterações em grande escala.

- **Manutenção de aplicações Angular + .NET** publicadas no IIS.
